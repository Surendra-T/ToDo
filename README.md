# Ledger

Built in under 5 minutes as part of the Global Hack Week: **Hacktoberfest 2026 Challenge**.

The challenge: build a quick, simple application using GitHub Copilot and Codespaces.

## What's built

Ledger is a simple, elegant todo app with:

- Local-only task storage using `localStorage`
- Add, complete, delete, and search tasks
- All items, open, and completed filters
- Light and dark theme switching
- Responsive desktop and mobile layout
- Old-money inspired visual design
